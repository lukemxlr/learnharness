How would you like to run LearnHarness?

Choose standalone local mode on this computer or connect to your self-hosted LearnHarness server.

Run locally

Store your chats, knowledge graph, and API keys directly on this computer with zero server setup.

Start local, move later: Don’t worry — you can seamlessly migrate your local chats, knowledge graph, and flashcards to a server anytime in Settings.

Connect to a server

Sync sessions, live streams, and iPad drawings through your self-hosted server (supports HTTPS, Cloudflare Access, LAN, and Tailscale).

Only enable on your own trusted home or Tailscale network (restarts the app once).
Don’t have a server set up yet? Follow the step-by-step Linux / Proxmox LXC guide (including prebuilt server bundles, Cloudflare Tunnel, and Tailscale HTTPS).
